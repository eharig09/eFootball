Method

Every team's offense and defense is rated separately on each measure, adjusted for the opposition it has faced, using only games before this one and carrying the earlier seasons in until this season has a real sample. Ranks and labels are relative to FBS teams, using league terciles on the same ratings. "This matchup" is what the offense's rating predicts against this defense's rating. This is description and an opponent-adjusted projection, not a pick and not the Football Lab number: in a 2023–2025 walk-forward its expected margin missed by about 12.8 points on average, against about 11.1 for the Football Lab margin, so the labels describe the matchup and never move a number.
