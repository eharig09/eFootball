# Research Outputs

Generated full research/backtest payloads should be written here rather than
dumped to the terminal or scattered through the repository.

JSON result files are intentionally gitignored. Keep terminal output compact
for review, while preserving the complete payload here for later analysis.

Current convention:

- `cfb_convergence_four_signal_through_<season>.json`

Research CLIs should create this directory automatically when needed and should
prefer descriptive, deterministic filenames unless a run specifically requires
versioned snapshots.
